A few useful details

Before you dive in.

Does scat run or change my scripts?

Ordinary search and browsing read the indexed catalog. Catalog builds and vc operations are separate, explicitly invoked administrator actions. Opening the TUI does not start an indexer or service.

Can I use it over SSH or without internet access?

Yes. The client reads your catalog offline and supports terminal glyph and color overrides for constrained sessions. Clipboard forwarding depends on your terminal. See the SSH and terminal guide.

Which systems does it target?

The main scat binary targets Linux x86-64. RHEL 8, 9 and 10 are the intended support matrix, with UBI userspace checks in CI. Actual host-policy and mount validation is site-specific; see the deployment guide. Windows is not supported by the main client.

Where do I report a problem?

Run scat doctor for read-only diagnostics, review the output for paths and host identifiers before sharing, and open an issue. For command help, run scat --help or press F1 in the TUI.
